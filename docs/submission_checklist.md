# Project 1 submission checklist

Requirements source: *Group Project Tutorial Recommender Systems*, general instructions on page 1 and Movie Recommendation on page 2. Project 2's retail-specific requirements do not apply.

| Requirement | Evidence |
|---|---|
| Shapes, null totals/columns, types, unique values | Report dataset section and column-inspection appendix; `results/dataset_column_evidence.csv` |
| Comparison dataset and information | `data/processed/dataset_comparison.csv`, generated by preprocessing and displayed in the app |
| Exploration and preprocessing | `figures/`, report, `src/data.py` |
| Reproducible split, relevance and held-out exclusion | README and `docs/reproduction_notes.md` |
| Exactly three required algorithm roles | Report algorithm section and reproduction comparison |
| At least five unseen films, titles, genres and comparison | Report same-user Top5; CSV has 20 users × 3 models × 10 films; verification checks complete history |
| Interactive user input | Streamlit app, including model comparison and data evidence tabs |
| README run commands, software, seeds, citations, output locations | README, direct lock, resolved environment and verification record |
| Report processing, findings and conclusions | `docs/technical_report.pdf` and Markdown source |
| Five-minute task/data/algorithms/evaluation/findings presentation | Six-slide PPTX and `docs/presentation_script.md` |

## Before uploading

- Confirm ItemKNN's lecture/chapter against the actual course slides. The project does not assert an unavailable lecture reference.
- Confirm group size is at most five, elect a leader and complete the required member-list email. Local files do not prove these actions were completed.
- Add the team's real names/student identifiers where required by the course. They have not been inferred from Git usernames or anonymized dataset users.
- Rehearse with a timer. Use the six-slide deck for the five-minute slot; the reviewed 24-page PDF contains outdated content and should not be presented unchanged.
- Run verification in the documented environment and retain the output. Do not report quick-run performance.
- Upload technical report, source code, README and permitted demonstration materials via Canvas. GitHub push alone is not Canvas submission.
- Do not redistribute raw MovieLens data, as required by the brief. This project also omits virtual environments, processed records and checkpoints from the source archive because they are rebuildable; omitting checkpoints is a packaging choice, not a separate course prohibition.
- Confirm the marker can reproduce the project from the source archive. Point them to the runbook and output paths; an external deployed app is not required.

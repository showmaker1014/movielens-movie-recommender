# Raw data

Download and extract the official MovieLens 1M archive here, or run:

```bash
python scripts/prepare_data.py --download
```

Expected files:

- `ratings.dat`
- `movies.dat`
- `users.dat`
- `README`

The raw archive and its contents are excluded from version control. Do not
redistribute the raw dataset or use it commercially without permission from
GroupLens.
